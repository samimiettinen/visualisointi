# Design worksheet

Use a short working copy for a substantial new deck or redesign. Fill it from the actual brief and sources. Omit irrelevant rows. For a minor repair, keep the reasoning in the working notes instead of producing another document. This worksheet is not a required user-facing deliverable or approval gate.

| Page | Audience question / purpose | Supported message | Evidence and source | Visual relationship / form | Required qualification | Main route or supporting detail |

Read the proposed titles in sequence, then inspect whether each visual supplies the evidence its title needs. A story that sounds persuasive can still be unsupported.

## Reusable pattern record, when relevant

- Question answered and required inputs:
- Intended reading mode and display size:
- Editable source and source/rights status:
- Invariants: scales, ordering, category meanings or geometry:
- Fields to replace: titles, data, dates, labels, notes, source references:

Use the longest actual label and densest required case to check the pattern. Do not create or update a persistent library unless that belongs to the task.

## Filled miniature example — fictional

**Job:** explain an exception route to operations staff, for a live walkthrough and later reference.

**Question:** what happens when a request fails the policy check?

**Evidence:** a fictional workflow defines requester, rules engine and reviewer; no timing data exists.

**Composition A:** a horizontal timeline. Weak fit: it would imply time and make the return route awkward.

**Composition B:** responsibility lanes with a labelled branch and return. Chosen because the question concerns ownership and conditions.

**Reading layers:** title identifies the exception; the route shows ownership; local labels explain approval and requests for more information. No timing or throughput is invented.

**Review:** the return arrow must reach the request stage; labels must be readable without the speaker. If a focus sequence is used, the objects stay in the same positions in both frames.
