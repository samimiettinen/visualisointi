# Review signals, not an aesthetic detector

The legacy linter IDs remain useful locators. A candidate is not proof of a defect or of AI authorship. The default profile changes aesthetic prescriptions into contextual review. `--strict-style` retains the older restraint-oriented output for a brief that explicitly wants it.

## Integrity and readability

| IDs | Inspect | Remedy when confirmed |
| --- | --- | --- |
| H1 | Unresolved placeholders | Resolve from the source or clearly identify an unavailable value |
| H3 | Forbidden names in a codename deck | Inspect visible and embedded material; remove genuine leaks |
| X0 | Unreadable input or missing inspection dependency | Repair the input or report the unperformed check |
| N4, N7 | Inconsistent formats or possible metric disagreement | Reconcile definition, period, entity, units and source |
| N5, N8 | Suspicious examples or excessive precision | Check provenance; label synthetic data and preserve warranted precision |
| K6, K7 | Unsupported claim or missing comparison baseline | Source and scope the claim; state the baseline |
| G1 | Perspective that distorts quantities | Use an accurate encoding |
| G5, G7, G9 | Unreadable labels, missing context or misleading axes | Repair the actual reading or interpretation problem |
| T7, L3 | Tiny text or overflow | Inspect intended display size, text role and intentional bleed |

The static scan cannot reliably compare every metric. Its numbers check uses text proximity and may confuse entities, adjusted/reported values, periods or rounding. It does not scan all images, chart workbooks or embedded files for confidentiality. Do not turn “no findings” into a factual or security certificate.

## Contextual signals

| IDs | Potential concern | Valid exceptions or better question |
| --- | --- | --- |
| N1, N3, N6 | Vague titles, unnecessary navigation, count mismatch | Descriptive diagram titles, real questions, reference pages and useful agendas are valid. A promised count should still match. |
| N2, N9 | Unstructured density | Self-read pages can be dense. Are the required details grouped and readable? |
| N10–N13, N15–N17 | Generic structure, repetition or weak ending | Repeat forms for comparison; close according to the actual occasion. |
| K1, K2, K4, K5, K8–K11 | Empty or inconsistent copy | Keep quotations, names and technical terms. Correct vague claims rather than mechanically deleting a word. |
| T1–T6, T8–T10 | Unclear type hierarchy or font problems | Bold, serif type, italics and short uppercase labels can work. Verify the font and reading hierarchy. |
| C1–C10 | Distracting effects or inconsistent colour roles | Gradients can encode quantities; categorical palettes and real brand colours are legitimate. |
| L1, L2, L4–L8, S1 | Weak grouping, drift or generic composition | Compare within layout families. Geometry in a diagram need not follow a spacing grid. |
| D1–D13 | Decoration that substitutes for explanation | A box can define a boundary, an arrow can explain a route, and a label plus colour can improve accessibility. |
| G2–G4, G6, G8, G10 | Chart form or styling mismatch | Select by the task; legends, markers and several hues can be useful. |
| I1, I2, P1–P4 | Filler images or icons | Prefer relevant, authentic evidence. Do not remove an informative image because its treatment is expressive. |
| M1–M6 | Motion that competes with the explanation | A controlled reveal or meaningful simulation can help; preserve a readable static state. |
| H2, H4 | Accidental scaffolding or missing disclosure | Keep required credits, provenance and confidentiality notices. |

## The opposite failure: excessive reduction

Check for a rich explanation reduced to a slogan, a distribution reduced to one average, a mechanism reduced to unconnected nouns, a comparison separated across pages, or an essential caveat moved into unreadable footnotes. These may pass a minimalism-oriented linter and still be poor design.
